# Reporting Terrain — version web (iPhone et navigateurs)

Application de reporting d'activité terrain, **hors ligne, sans compte et sans serveur de données** :
les informations saisies restent sur l'appareil de chaque utilisateur.

Ce dépôt ne contient que le programme (dossier `public/`), publié par Cloudflare (`wrangler.jsonc`).
Il est généré automatiquement à partir du projet principal : ne pas le modifier à la main.

## Installer sur iPhone
1. Ouvrir l'adresse de l'application dans **Safari**.
2. Toucher **Partager** puis **Sur l'écran d'accueil**.
3. Ouvrir l'application depuis son icône : elle fonctionne ensuite sans Internet.
